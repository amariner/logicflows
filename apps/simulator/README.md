# Simulador

Reproduce una célula de paletizado sin hardware real: el ciclo de cajas y pallets, los estados de [ADR-0003](../../docs/adr/0003-estados-de-la-paletizadora.md), los fallos y escenarios de red adversos. Publica la telemetría en el broker MQTT.

TypeScript sobre Node.js. La primera versión se implementa en LF-25.
